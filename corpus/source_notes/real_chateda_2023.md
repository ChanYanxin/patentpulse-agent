# Source note: ChatEDA LLM agent for EDA (2023)
TYPE: Independently source-identified PUBLICATION SUMMARY, written for TechIntel demo; NOT the paper full text. Verify the publication directly before quoting results.
SOURCE: Zhuolun He et al., "ChatEDA: A Large Language Model Powered Autonomous Agent for EDA," arXiv preprint, 2023.
URL: https://arxiv.org/abs/2308.10204
ChatEDA proposes using a large language model agent as a controller that coordinates electronic design automation tools. The authors call the language-model controller AutoMage and describe task decomposition, script generation and tool execution for RTL-to-GDSII workflows.
The agent-oriented distinction is that an EDA tool performs specialized synthesis or physical design, while the language model interprets user goals and orchestrates tools. Paper-reported comparative results are not measurements of TechIntel.
研究要点：ChatEDA 通过模型协调 EDA 工具，从 RTL 到 GDSII，体现任务拆解、脚本生成、工具调用和工程流程自动化的 Agent 模式。
